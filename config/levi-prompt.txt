In LGL, features go in `app/src/main/jni/Main.cpp` as `OBFUSCATE()` strings in a
`features[]` array: `Toggle_`, `SeekBar_Name_min_max`, `Category_`, `Collapse_`,
`CollapseAdd_`, `Spinner_Name_a,b,c`, `Button_`, `ButtonLink_`, `ButtonOnOff_`,
`CheckBox_`, `InputValue_`, `InputText_`, `RadioButton_`. A leading number sets the
ID; `True_` after the prefix turns it on by default. Menu setup, dialog, toast and
icon are in `app/src/main/jni/Menu/Menu.cpp`. Hooks use Dobby, memory uses
KittyMemory, library loading uses xDL.
